# Product Preview Card Component

This is a solution to the Product preview card component challenge on Frontend Mentor.

## 📋 Project Description
A clean, modern product preview card featuring a perfume bottle. This project focuses on building a responsive layout that changes from a two-column desktop view to a single-column mobile view, while maintaining high-quality typography and spacing.

## 🚀 Demo
[Live Preview](https://fokasdev.github.io/Product-preview-card-component/)

## 🛠️ Built With
* **Semantic HTML5** – For structured and accessible content.
* **CSS3 Custom Properties** – Using variables for consistent colors and fonts.
* **Flexbox** – To handle the card's alignment and responsive layout.
* **Mobile-first workflow** – Ensuring a seamless experience on all devices.
